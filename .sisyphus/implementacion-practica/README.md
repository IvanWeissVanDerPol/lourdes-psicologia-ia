# IMPLEMENTACIÓN DE PRÁCTICA ESTUDIANTIL

> **Objetivo:** Guía paso a paso para Lourdes para iniciar y gestionar su práctica de coaching/bienestar durante sus estudios de psicología
> **Base Legal:** Estudiante de psicología, NO uso del título "psicóloga", divulgación clara de estado
> **Fase Actual:** Pre-licencia (meses 1-12)

---

## 📋 Modalidad de Trabajo

### **Servicios Permitidos**
- ✅ **Coaching de bienestar** - Apoyo emocional, desarrollo personal
- ✅ **Acompañamiento emocional** - Escucha activa, contención
- ✅ **Análisis con IA** - Patrones de comunicación (con consentimiento)
- ✅ **Técicas de mindfulness** - Ejercicios de respiración, meditación
- ✅ **Coaching de vida** - Metas, hábitos, organización
- ✅ **Facilitación de grupos** - Workshops pequeños con amigos

### **Servicios NO PERMITIDOS**
- ❌ **Terapia clínica** - No diagnosticar trastornos mentales
- ❌ **Tratamiento de condiciones psiquiátricas** - No intervenir en crisis psiquiátrica
- ❌ **Evaluación psicológica formal** - No usar tests psicométricos
- ❌ **Uso del título profesional** - No presentarse como "psicóloga licenciada"

## 📅 Fase 1: Inicio (Meses 1-3)

### **Mes 1: Setup y Primeros Clientes**

#### **Semana 1: Preparación**
- [ ] **Día 1-2:** Configurar APIs (OpenAI, Anthropic)
- [ ] **Día 3-4:** Crear scripts de análisis básicos
- [ ] **Día 5-7:** Practicar con amigos/familia
- [ ] **Fin de semana:** Documentar aprendizajes

#### **Semana 2-4: Primeros Clientes**
- [ ] **Objetivo:** 3-5 clientes de práctica
- [ ] **Frecuencia:** 1-2 sesiones/semana
- [ ] **Presupuestos:** Gs. 30-50K por sesión
- [ ] **Foco:** Amigos cercanos, familiares, compañeros de estudios

#### **Semana 3-4: Expansión**
- [ ] **Objetivo:** 5-8 clientes
- [ ] **Frecuencia:** 2-3 sesiones/semana
- [ ] **Estrategia:** Referidos de primeros clientes

#### **Mes 5-8: Optimización**
- [ ] **Objetivo:** 8-12 clientes
- [ ] **Frecuencia:** 3-4 sesiones/semana
- [ ] **Refinamiento:** Ajustar técnicas basado en feedback

### **Mes 1-3: Hitos Clave**
- **Meta de Ingresos:** Gs. 500K-800K
- **Clientes Totales:** 12-15 clientes
- **Sesiones Totales:** 50-80 sesiones
- **Sistema IA:** Funcional básico probado

## 📈 Fase 2: Desarrollo y Consolidación (Meses 4-6)

### **Objetivo General**
- Construir base sólida de clientes
- Desarrollar y refinar sistema IA
- Generar Gs. 10-15M para inversión profesional

### **Mes 4-6: Escalado Operaciones**

#### **Sistema de Citas**
- Calendario compartido (Google Calendar)
- Recordatorios automáticos (Messaging)
- Confirmaciones con 24 horas de anticipación
- Política de cancelación (50% si no avisa)

#### **Gestión de Clientes**
- Base de datos simple (Airtable o Google Sheets)
- Archivo por cliente (carpeta por persona)
- Seguimiento de progreso y objetivos

#### **Desarrollo de Contenido**
- Blog con consejos de bienestar emocional
- Posts educativos en Instagram (3x/semana)
- Newsletter mensual con insights

#### **Red de Referidos**
- Programa formal: 10% descuento referidor + 5% descuento referido
- Material de referido (tarjetas, flyers digitales)
- Seguimiento de efectividad

## 📋 Guía de Sesión Estudiantil

### **Estructura de Sesión (50 min)**

#### **1. Apertura (5 min)**
- Bienvenida y check-in emocional
- Recordar consentimientos (grabación, análisis)
- Establecer clima de confianza

#### **2. Desarrollo Principal (35 min)**
- Coaching activo y escucha
- Técnicas de reencuadre y preguntas poderosas
- Identificación de patrones positivos

#### **3. Cierre (10 min)**
- Resumen de insights y avances
- Tareas y compromisos para siguiente sesión
- Coordinación próxima cita

## 🧠 Análisis con IA

### **Flujo de Análisis**

#### **1. Transcripción**
```
Audio Sesión → Whisper API → Transcripción
```

#### **2. Análisis de Contenido**
```
Transcripción + Contexto → Claude/GPT → Insights Psicológicos
```

#### **3. Documentación**
```
Insights → Template → Perfil del Cliente
```

### **Categorías de Análisis**

| Categoría | Qué Busca | Cómo Se Usa |
|-------------|------------|--------------|
| **Comunicación** | Patrones de diálogo, estilo expresivo | Frecuencia y longitud de mensajes |
| **Emociones** | Palabras emocionales, estados de ánimo | Intensidad y variación |
| **Mecanismos de Defensa** | Intelectualización, minimización, proyección | Estrategias de autoprotección |
| **Necesidades** | Deseos explícitos, carencias implícitas | Prioridades y urgencias |
| **Dinámicas** | Roles en relaciones, patrones de apego | Interacciones con figuras clave |
| **Crecimiento** | Cambios en el tiempo, logros | Evolución de patrones |

## ⚖️ Ética y Límites

### **Principios Éticos**
1. **Consentimiento Informado:** Siempre explícito, específico
2. **Confidencialidad:** Proteger datos de clientes
3. **Competencia:** No trabajar fuera de áreas de competencia
4. **Supervisión:** Buscar consulta si hay dudas éticas

### **Límites Profesionales**
- **Tiempo de sesiones:** 50 minutos máximo
- **Comunicación fuera de sesión:** Solo mensajes grupales o individuales por Messaging
- **Emergencias:** Protocolo de derivación profesional
- **Autocuidado:** No offrir terapia personal al terapeuta

### **Señales de Alerta**
- Intervención con más clientes de los que puedes manejar
- Trabajo terapéutico para ti mismo
- Consulta con supervisor/mentor
